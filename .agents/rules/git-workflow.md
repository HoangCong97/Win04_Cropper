# Quy tắc Git Workflow

- **Chỉ commit và push khi người dùng ra lệnh**: Chỉ thực hiện `git commit` và `git push` khi người dùng yêu cầu rõ ràng trong yêu cầu của họ.
- **Không tự động commit/push**: Tuyệt đối không tự động commit hoặc push code sau khi sửa đổi hoặc hoàn thành các tác vụ khác nếu người dùng không yêu cầu.
